# 阈值速查（question-bank-qc）

> 本文件是 `SKILL.md` 的数值附表。改动题库规模时，先改 `verify.py` 顶部 `FILES`，再同步本表。

## 1. 题量与题型

| 库 | 题数 | 题型 | 说明 |
|---|---|---|---|
| `choice.json` | 500 | 单选 450 + 多选 50 | 每题 4 选项 |
| `fill.json` | 50 | 填空 | 每题 3 空，占位符 `____①____` 等 |
| `fix.json` | 50 | 改错 | 每题 2 处，代码 7–15 行 |
| `rutuan-q16-19.json` | 4 | 代码/设计 | 10/15/15/25 = 65 分 |
| `zhaosheng-b-q16-19.json` | 4 | 代码/设计 | 10/15/15/25 = 65 分 |

## 2. 难度

| 库 | 口径 | 目标分布 |
|---|---|---|
| choice 单选 | 1/2/3 | 150 / 150 / 150（±2） |
| **choice 多选** | **统一 9** | 50 题全部 = 9 |
| fill | 1/2/3 | 17 / 17 / 16 |
| fix | 1/2/3 | 17 / 17 / 16 |
| 大题 | 1/2/3/4 | 各 1 题 |

难度定义：

- 1 = 单一语法/概念，或 ≤3 行代码直接求值；
- 2 = 4–8 行代码跟踪，含 1 个边界/陷阱；
- 3 = ≥9 行代码，或 ≥2 个陷阱/两步推理；
- 4 = 开放设计（仅大题）。

## 3. 答案与选项

| 项 | 阈值 |
|---|---|
| 单选项字母分布 | 每项 18%–32%（`verify.py` 硬门禁）；建议 100–125 题/项（22%–28%） |
| 与 `"ABCD"[i%4]` 吻合率 | < 35% |
| 选项数 | 恒 4 |
| 选项文本 | 互不相同；去首尾空白后仍互不相同 |
| 多选正确项 | 2–3 个，升序 |
| 多选答案键 | 不得全部正确/全部错误 |

## 4. 重复

| 项 | 阈值 |
|---|---|
| 库内题干逐字重复 | 0 |
| 跨库题干逐字重复（choice/fill/fix 两两） | 0 |
| 骨架族最大题数 | ≤ 4 |
| 骨架种类 | choice ≥ 120；fill/fix ≥ 30 |
| 相似度 ≥0.95 题对 | 0（人工复核） |

## 5. 判题

| 项 | 阈值 |
|---|---|
| fill 官方答案回填 | 50/50 通过 |
| fill 空位错误值注入 | 必须失败；域内等价需逐条说明 |
| fix 官方答案 | 通过 |
| fix 原始代码 | 必须失败 |
| fix 撤销任一修改 | 必须失败 |
| judge tests | ≥3 条，含至少 1 条边界 |
| harness 文件写 | 禁止（error） |
| 单题超时 | 5 秒 |

## 6. 代码排版

| 项 | 阈值 |
|---|---|
| 完整程序（`int main`） | 禁止单行围栏块 |
| 单行围栏块 | ≤40 字符 |
| 程序片段 | 禁止行内代码 |
| 缩进 | 4 空格；`{`/`}` 独占行（`qc.py` V2 检查，warning；`verify.py` 只查单行/行内程序） |

## 7. 元数据

| 项 | 阈值 |
|---|---|
| 题目 id | 608 个全局唯一（人工/脚本统计；`verify.py` 只查库内唯一） |
| exam_id | 5 个互不相同，带版本后缀 |
| pick | choice 50；fill/fix 10；大题 4（可按考务调整，须 ≤ 题量） |
| kp | 原 51 点全覆盖；越纲 0 |

## 8. 时间预算

| 动作 | 参考耗时 |
|---|---|
| `verify.py` 完整模式 | 2–3 分钟（500 次编译） |
| `check_choice.py --all` | 40–60 秒（8 并发） |
| `fill_inject.py` 全量 | 1–2 分钟 |
| 10 秒内 PASS | 必是 `--no-compile`，不是完整门禁 |
