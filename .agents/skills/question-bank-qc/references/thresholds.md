# 阈值速查（question-bank-qc）

> 本文件是 `SKILL.md` 的数值附表，口径来源为题库仓 `ees-banks/difficulty.md` + `verify.py` + `score.py`（2026-11-18 口径）。
> 改题库规模时：先改 `verify.py` 顶部 `FILES`（门禁常量），再同步本表与 `assets/report-template.md`；**规范阈值不要改**，只改“当前库规模”。

## 0. 规范阈值 vs 门禁常量

| 项 | 规范（不可改） | 门禁常量（随库改） |
|---|---|---|
| choice | 500（单选 450 + 多选 50） | `FILES["choice"] = 500` |
| fill | **每档 ≥15 题，总量不限** | `FILES["fill"] = 60`（当前库规模） |
| fix | **每档 ≥15 题，总量不限** | `FILES["fix"] = 61`（当前库规模） |
| 大题 | 每库 30 题、全部难度 3、每题 15 分、总分 450 | `FILES["rutuan"/"zhaosheng"] = 30` |

> 规范只设**下限/上限**，门禁按**当前库规模精确校验**。两者不一致时，改 `FILES` 并在报告里写明“口径对齐”；不得为了过门禁删题。

## 2. 难度

```text
S = 0.35 × K + 0.45 × A + 0.20 × C        K∈1..3  A∈1..4  C∈1..4
```

| 题型 | 分档 |
|---|---|
| 单选 / fill / fix | S<1.90 → 1；S<2.55 → 2；否则 3 |
| 大题 | S<1.75 → 1；S<2.60 → 2；S<3.30 → 3；否则 4（**现行口径：全部固定 3**） |
| 多选 | 真实 S∈**[2.00, 2.20]**；JSON `difficulty` 固定 **9** |

当前库分布（`score.py` 实测，2026-11-18）：

| 库 | 难度分布 | 备注 |
|---|---|---|
| choice 单选 | 180 / 137 / 133 | 无配额切档，纯 S 决定 |
| choice 多选 | 50 × 9 | 每题 `{k:3,a:2,c:1}` → S=2.15 |
| fill | 26 / 19 / 15 | 3 档仅 15 题（下限） |
| fix | 28 / 18 / 15 | 3 档仅 15 题（下限） |
| rutuan / zhaosheng | 30 × 3 | 每题 `{k:3,a:3,c:2}` → S=2.80 |

约束：

- 同一 S 必同档，禁止按题号/位置/配额切档；
- choice / fill / fix 任一难度档占比 ≤60%（`verify.py` 硬校验；大题不参与）；
- fill / fix 的 1/2/3 档每档 ≥15 题（`verify.py` 硬校验）；
- 每题 MUST 有 `meta.scoring={k,a,c}` 的**整数**标注；缺失不是“默认值”，是缺陷（`verify.py` 不报缺失，`qc.py` V4 报 REVIEW）。

## 3. 答案与选项

| 项 | 阈值 |
|---|---|
| 单选项字母分布 | 每项 18%–32%（`verify.py` 硬门禁；实测 112–113/450 ≈ 25%） |
| 与 `"ABCD"[i%4]` 吻合率 | <35% |
| 选项数 | 恒 4 |
| 选项文本 | 互不相同；去首尾空白/不可见字符后仍互不相同 |
| 多选正确项 | 2–3 个，升序；不得全选/全不选 |
| 多选陈述 | 每题 4 条独立单事实陈述，单条 12–35 字，无嵌套推理 |
| 多选主观分布 | 目标 10 易 / 35 中 / 5 难（中档 70%，复核人判；现库实测约 13/30–31/6–7，见 report §14.3） |

## 4. 重复 / 骨架 / 跨库

| 项 | 阈值 |
|---|---|
| 库内题干逐字重复 | 0 |
| 跨库题干逐字重复（choice/fill/fix 两两） | 0 |
| 骨架族最大题数 | ≤4（掩数字/代码块后同骨架） |
| 骨架种类 | choice ≥120；fill/fix ≥30 |
| 句式族（掩标识符后同壳） | ≤4，建议 ≤3（`qc.py` V3 warning） |
| **跨库同任务** | 同一任务族在任一库 ≤ **20%** 题量（大题 30 题 → ≤6 题）；两库各 1 次 = 3.3% 属接受范围 |
| 相似度 ≥0.95 题对 | 0（人工复核） |

 > 20% 只用于**任务级**重复（大题：求和/计数/匹配/求值等换个题面）。choice/fill/fix 已有更严的骨架族 ≤4，不再叠加 20%。

## 5. 判题

| 项 | 阈值 |
|---|---|
| fill 官方答案回填 | 60/60 通过 |
| fill 空位错误值注入 | 必须失败；域内等价需逐条说明（`qc.py` V8 记 REVIEW；`fill_inject.py` 记 UNPINNED） |
| fix 官方答案 | 通过（61/61） |
| fix 原始代码 | 必须失败 |
| fix 撤销任一修改 | 必须失败（两处都要独立可测） |
| judge tests | ≥3 条，含至少 1 条边界 |
| harness 文件写 | 阻断（`qc.py` V7 error；`verify.py` 仅 warning） |
| 单题超时 | 5 秒 |

## 6. 代码排版

| 项 | 阈值 |
|---|---|
| 完整程序（`int main`） | 禁止单行围栏块 |
| 单行围栏块 | ≤40 字符（`verify.py`：>40 且含 `;` 即 error） |
| 程序片段 | 禁止行内代码 |
| 缩进 | 4 空格；`{`/`}` 独占行（`qc.py` V2 检查，warning；`verify.py` 只查单行/行内程序） |

## 7. 元数据

| 项 | 阈值 |
|---|---|
| 题目 id | 681 个全局唯一（`verify.py` 只查库内唯一，跨库需脚本/人工） |
| exam_id | 5 个互不相同，带版本后缀，无路径分隔符/保留名 |
| pick | choice 50；fill/fix 10；大题 4（可按考务调整，须 ≤ 题量） |
| kp | 原 51 点全覆盖；越纲 0；编号形如 `1.1`–`12.9` 且在 51 点集合内 |
