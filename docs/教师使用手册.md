# 保密考试系统 · 教师使用手册

面向使用者：**出题老师 / 考务老师**。不需要懂编程，不需要安装任何开发工具。

---

## 0. 你手上有什么

拿到的是一个文件夹（例如 `ExamAdmin`），里面：

| 文件 | 作用 | 你需要做什么 |
|---|---|---|
| `ExamAdmin.exe` | 管理端程序，双击打开 | 平时用它配题、打包 |
| `stub-template.exe` | 学生端模板 | **不要发给学生**，只在打包时被程序内部使用 |
| `图片使用教程.md` | 怎么在题库里加图片 | 第一次插图时看 |
| `示例题库\` | 拿来就能试的题库（含图片题） | 第一次用时导入试试 |
| `使用说明.md` | 本文件 | — |
| `_internal\` | 程序运行需要的库 | 不要删除、不要改动 |

> ⚠ **整个文件夹要一起保留**。只把 `ExamAdmin.exe` 拿出来是打不开的。

---

## 1. 五分钟上手

### 第 1 步：导入题库

1. 双击 `ExamAdmin.exe`
2. 切到 **[题库]** 标签
3. 点 **[导入题库…]**，选中你的 JSON 题库文件（可一次选多个）

**题库 JSON 格式**（一份文件就是一门科目）——完整规范见 [`docs/题库JSON规范.md`](题库JSON规范.md)：

```json
{
  "exam_id": "math",
  "title": "高等数学",
  "pick": 20,
  "questions": [
    {
      "id": "m001",
      "type": "single",
      "stem": "1+1=?",
      "options": ["1", "2", "3", "4"],
      "answer": "B",
      "score": 2
    }
  ]
}
```

| 字段 | 含义 | 注意 |
|---|---|---|
| `exam_id` | 内部标识 | 英文数字，**不要重复** |
| `title` | 学生看到的科目名 | 随便写中文 |
| `pick` | 默认抽几题 | 不能超过题量 |
| `questions[].id` | 题目编号 | 同一题库内不能重复 |
| `type` | `single` / `multiple` / `judge` / `fill` / `fix` / `essay` | |
| `answer` | 标准答案 | 会随题库被打包，**学生看不到**；`essay` 可留空 |

> `essay`（问答题）：学生端给**多行输入框**作答，管理端**人工给分**（不参与自动判分）。
> 其余题型都能自动判分。

> 💡 **文件必须是 UTF-8 编码**。用记事本另存为时选「UTF-8」；
> VS Code 里点右下角编码 → Save with Encoding → UTF-8。
> 存成 GBK 的话程序会明确提示你。

#### 另一种格式：题目与答案分成两个文件

如果你的题库是 `X.questions.json` + `X.answers.json` 这种成对文件
（`format_version: 2`，内容里有 `content.kind`），**两个文件一起选中**导入即可：

- 文件名相同、后缀不同就会自动配对；只选题目文件时程序也会在同目录找答案文件；
- 导入时会逐条校验：id 一一对应、题型与答案类型匹配、选项键连续、
  模板占位符数量与 `blank_count` 一致、改错的行号与原文匹配；
- 校验不通过会**拒绝导入**并指出是哪个文件第几条、错在哪；
- 通过后会弹「确认导入」，可以在那里把题库 ID（用于文件名）和显示名称改成看得懂的名字。

> 这类题库的答案与判分材料（题库字段 `judge`，注意与 `type: judge` 判断题区分）
> 只保存在工程里，**打包时会被剥离**，
> 学生端永远看不到。

#### 题干里可以写代码块、表格、图片

题干支持一小部分 Markdown，学生端会渲染成对应样式：

| 写法 | 效果 |
|---|---|
| ` ```c … ``` ` | 代码块（等宽 + 底纹） |
| `` `int x` `` | 行内代码 |
| `**重点**` | 加粗 |
| `- 项` / `1. 项` | 列表 |
| `> 文字` | 引用 |
| 竖线表格 + 分隔行 | 表格（列多时底部可左右拖动） |
| `![说明](data:image/png;base64,…)` | 图片 |

**插入图片**：在 **[题库]** 页点 **[插入图片…]**，选一张 PNG/JPEG →
程序会自动检查尺寸与体积，并把 `![说明](data:image/…)` 复制到剪贴板 →
粘到题库 JSON 的 `stem` 字段里（必须**独占一行**）。

选项（题支）也可以多行、可以放代码块（整块可点选）；选项里不能放图片。

三条限制：

1. 图片只支持 PNG/JPEG，**建议** ≤1.5 MB、≤1200 px（学生端硬上限 4 MB / 4096 px，
   超过会显示 `[图片无法显示]`）；
2. 表格必须有表头行和 `|:--|` 这样的分隔行，否则按普通文字显示；
3. 链接、斜体、嵌套列表不支持，会按纯文本显示。

图片太大怎么办：用系统「画图」或任何看图软件把宽度改到 1200 px 以内；
照片存成 JPEG（体积通常只有 PNG 的 1/5），截图/线条图存成 PNG。

完整清单见 `docs/题库JSON规范.md` 1.3.1；
手把手教程见随包的 `ExamAdmin\图片使用教程.md`；示例题库是 `示例题库\图片题示例.json`（解压后的根目录）。

### 第 2 步：填学生名单

1. 切到 **[学生]** 标签
2. 把学号粘进大文本框，**每行一个**（也支持逗号、空格分隔）
3. 点 **[应用为学号名单]**

可以直接从 Excel 复制一列粘进来。也可以点 **[从 CSV 导入…]**。

学号必须是**正整数**。重复的、非数字的会在框下方提示，点应用时会被拦住。

#### 按班级管理名单（推荐给多班老师）

1. 在 **[学生]** 页左侧点 **[新建班级…]**，输入班级名（可另填编号，如 `CS2101`）；
2. 选中该班，把学号粘进右侧框，点 **[应用到名单]**——
   新学号会**自动加入全局名单**，不需要再去「全部学生」里加一遍；
3. 左侧还有两个视图：
   - **全部学生**：整个学号池（原有行为）；
   - **未分班**：**只读**视图（不能在这里改名单，也不能导入 CSV），
     只用来核对还有谁没分到班。要改这些学生，请到「全部学生」里改。

> 班级成员永远是「全局名单」的子集：从全局名单里删掉一个学号，
> 所有班级里的他也会一并消失，不会留下"幽灵学生"。

### 第 3 步：编排场次

1. 切到 **[场次]** 标签
2. 点 **[新建]**
3. 填：场次编号（自动给）、开始时间、结束时间
4. 学号名单选「使用全部学生」/「按班级选择…」/「自定义名单」
   > 名单是**保存时的快照**：之后在学生页加人，这里点「使用全部学生」会显示最新名单，
   > 但**已保存的场次不会自动更新**，要重新点一次 [保存此场次]。
   - **按班级选择…**：勾选一个或多个班，成员自动并入本场；
   - 选完会切回「自定义名单」，下方会显示「本场 N 人，来自 M 个班」，
     用来核对是不是漏加了某个班；
5. 在 **[考试科目]** 里勾选本场要考的科目，填每题抽几道；
   需要控制难度时，勾选「限制平均难度」并填 `1–255` 的区间——
   系统会保证抽出的这 N 题平均难度落在区间内；界面会实时显示该库抽 N 题的**可达平均分范围**，
   区间不可行时保存会报错
6. 点 **[保存此场次]**

> **设计边界（刻意如此，请勿改动）**：难度区间只约束抽出的这 N 题的**平均难度**，
> **不**对单题设最高/最低限制。允许出现个别很难或很简单的题，只要平均在区间内。
>
> 设置区间前，该题库**所有题**都必须标好 `difficulty`（1–255）；有未标注的题会被拦下。

**底部的时间轴**会把所有场次画出来：

- 蓝色 = 正常
- **红色 = 时间重叠**

> ⚠ **红色重叠要处理**：如果同一名学生同时出现在两个重叠的场次里，
> 系统无法判断他该考哪一场，打包时会直接报错。
> 解决办法：把时间错开，或把这些学生从其中一场移除。
>
> 只是时间重叠、学生不重叠（比如同一天上午两个班）是允许的。

### 第 4 步：打包

1. 切到 **[打包]** 标签
2. **主密钥**：点右侧 **[生成]** 自动生成一个（生成时会显示进度条，通常 1–2 秒）
   - 🔑 **这是全系统最重要的东西**。立刻存进密码管理器。
   - 丢了不影响已发的包（密钥已写进包内），但**无法再打新包**给学生。
   - 不要写进任何文件、不要发微信、不要放共享盘。
   - 打包前后都可以点右边的 **[复制主密钥]**，把它粘到密码管理器里保存；
     下方会提示「主密钥已复制到剪贴板，请妥善保管」。
   - 日志里**不会**出现主密钥——日志可能被截图或留在共享电脑上。
3. **学生端 stub**：保持默认（指向 `stub-template.exe`）
4. **输出包**：选一个保存位置，例如 `D:\考试\12月20日高数.exe`
5. 点 **[开始打包]**

打包过程中下方会实时滚动日志。几分钟内完成（1500 人约 7 秒）。

看到这一行就成功了：

```
✔ 已内嵌密钥：学生双击 exe 输入学号即可，无需任何参数或密钥文件。
```

---

### 第 5 步：判分与成绩导出

1. 打开 **[收卷判分]** 页，把学生交上来的 `answers-*.eea` 拖进来；
2. 填主密钥（可只填一次），选学生端包，点 **[开始校验]**；
3. 在「自动判分」里勾选**要自动判的题型**（默认单选/多选/判断），
   可选"忽略大小写/忽略空白/填空/改错按项给分"；
4. 点 **[预检]** 看有没有"题库里找不到的题号"、"没有标准答案的题"，
   或"与所选包不匹配的答题卡（binding=false）"；
5. 点 **[生成成绩]**：表格列出每题的学生作答、标准答案、得分；
6. **双击"得分"列可以改分**（未判的题、判错需要人工调整的题都在这里补录）：
   - 已判题：显示 `原分 → 新分`；
   - 未判题（问答/未勾选的题型）：显示 `人工 N`，**打 0 分也有效**；
   - 清空得分 = 撤销人工评分，回到「待人工判分」；
7. 点 **[导出判分结果…]** 选目录，会生成五个 CSV（文件名带导出时间，不会覆盖上一场）：
   - `已判分-明细-<时间>.csv`（逐题，含"人工调整"与"调整时间"）
   - `已判分-汇总-<时间>.csv`（每生一行）
   - `未判分-<时间>.csv`（没勾选自动判的题，供人工判）
   - `全量-<时间>.csv`（两者合并）
   - `考生成绩表-<时间>.csv`（**按学号排序**，每种题型两列"得分/满分"，
     带班级、总分、得分率、未判题数与"完整/含未判"状态）

> 成绩表的**满分按整卷统计**（含还没判的题）；未判题不计得分，所以
> "得分率"是部分成绩——状态列写着「含未判」就说明还没判完。

> 导出目录里还会有一份 `说明.txt`，写明本次的判分口径与时间，便于复核。

> 改了主密钥/换了包之后，旧成绩会自动清空——不会出现"导出的分数和当前输入对不上"。

**问答题怎么判**：生成成绩后，问答题显示「待人工判分」、得分 0/满分。
双击「得分」列输入分数即可——**会自动计入汇总，并进入「已判分-明细」**；
没打分的仍留在「未判分 CSV」（含题干摘要，方便对着改）。

## 2. 考试当天

### 你要做的

1. 把打好的 `.exe` 通过班级群 / U 盘 / 内网共享发给学生
2. 告诉学生：「双击打开，输入学号，点开始考试」
3. 到时间窗口自动放行，不到时间会提示「考试尚未开始」

### 学生要做的

1. 双击 exe
2. 输入学号
3. 点 **[开始考试]**
4. 看到题目

学生**不需要**任何密钥文件、不需要输入密码、不需要配置任何东西。

页面顶部会显示**实时走动的网络时间**和「距离结束还有 …」；
**到达结束时间后页面自动关闭**（显示「本场考试已结束」），不能再查看题目；
此时答题卡会**自动冻结并写盘**，可以直接从学生机拷走（见 2.6 节）；
页面下方会显示版本与作者信息（与启动时的欢迎弹窗一致）。

### 时间门禁是怎么判定的

程序会联网向三个国内站点（百度、阿里、腾讯）取时间，取中位数。

- 至少要有 **2 个源**成功，否则拒绝解锁
- 三个源之间分歧超过 **300 秒**，拒绝解锁
- 学生本机时钟被改？没用——以网络时间为准
- 学生断网？**拒绝解锁**（这是刻意的：宁可考不了，也不能让时钟作弊）

> 💡 考场建议：提前让学生连好网、用同一台设备试跑一次
> （拿一个「测试学号」打个测试包，不要用真名单）。

## 2.5 查看版本号

管理端窗口右上角（工具栏最右侧）显示水印：

```
EES v<版本号> Powered by AlbusRiddle
```

学生端窗口最顶部也显示同一串。**反馈问题时请把这一行一起发来**，
能直接定位到具体版本。

## 2.6 收卷与答题卡

学生端会在**学生作答时**自动把答题卡加密保存到本机：

| 位置 | 说明 |
|---|---|
| 学生端 exe 同目录 `answers-<学号>-<场次>-<试卷指纹8位>.eea` | 首选；监考可直接拷走。**文件名带指纹**：同一台机器上开多份包不会互相覆盖 |
| `%LOCALAPPDATA%\ExamSystem\answers\` | 同目录不可写（Program Files / 只读 U 盘）时的回退位置 |

- **到点自动冻结**：结束时刻一到，答题卡写入"已交卷"，界面不再接受修改；
- **提前交卷**：学生可点【交卷】，需连点两次确认；交卷后**直接进入「已交卷」页**
  （显示交卷时间），不会再停留在试卷上；
- 右侧题号卡：**已答=蓝色**、**未答=灰色**、**当前题=绿色描边**，方便学生检查漏答；
- 文件是密文，**不能用记事本打开**，必须用管理端校验。

### 校验答题卡（管理端「收卷判分」页）

1. 打开 **收卷判分** 页；
2. 粘贴**主密钥**（与打包时同一把）；
3. （推荐）选择**学生端包**——用于核对"这份答题卡确实属于这个包的这个学生"；
4. 【添加文件】选中学生交上来的 `.eea`（可多选，也可整个文件夹）；
5. 【开始校验】→ 表格显示学号、场次、题数、已答/未答、交卷时间、校验结果：
   - **✓ 通过（已绑定）**：文件与包、学号、试卷指纹全部对得上；
   - **✓ 通过（未校验绑定）**：没选学生端包，只做了"能不能解开"，**不能证明这份卡属于这个包**；
   - **✗ 失败**：鼠标悬停状态列可看具体原因；
6. 【导出原始作答 CSV】——一行一题，Excel 可直接打开（不含分数；判分用下方的「导出判分结果…」）。

#### 缺考名单

校验完成后点 **[缺考名单…]**，程序会按场次把"应到名单"和"收上来的卡"对起来：

| 状态 | 含义 |
|---|---|
| 已交卷 | 有卡且已交卷 |
| 未交卷 | 有卡但没点交卷（自动保存的） |
| **缺考** | 名单里有、但没有卡 |
| 校验失败 | 有卡但解不开/与所选包不匹配 |
| 名单外 | 有卡但学号不在该场名单里 |

- 顶部可勾选「包含没有答题卡的场次」（默认不勾，防止只导了一个场的卡就把别的场全标缺考）；
- **[复制本场缺考学号]** 方便发通知；
- **[导出缺考名单…]** 生成 `缺考名单-<时间>.csv`（场次/学号/班级/状态/说明）。

也可以命令行校验：

```bash
EXAM_MASTER=<64 位主密钥> exam-builder verify-answer-sheet answers-2021001-1.eea --package 学生端.exe
```

退出码：`0` 通过 / `2` 解密失败 / `3` 结构错误 / `4` 绑定不匹配 /
`5` 包用不了（不同 master 的包、包里没这个场次或学号）或参数/IO 错误。

> **安全边界**：答题卡用包内的 `K_manifest` 派生密钥加密，学生原则上能还原密钥，
> 因此加密只能防"随手改"，不能防蓄意篡改。真正的可信依赖现场监考收卷。

## 3. 常见问题

### 「题库必须是 UTF-8 编码」

题库文件被存成了 GBK（Windows 记事本默认）。用记事本打开 → 另存为 → 编码选 UTF-8。

### 「场次 1 与 2 时间重叠，且学生 … 同时在两场」

同一个学生被排进了两个时间重叠的场次。系统无法判断他该考哪场。
去 **[场次]** 标签调整时间，或修改名单。

### 「场次 1 重复引用题库 math.json」

同一场次里勾了两次同一门科目。去掉一个。

### 「学号必须是正整数」

名单里有 0、负数、或非数字的内容。检查文本框。

### 学生报「学号 2021001 不在场次 1 的名单中」

这个学号没被排进当前场次的名单。去 **[学生]** 和 **[场次]** 检查。

### 学生报「考试尚未开始」

还没到开始时间。程序显示的时间是网络时间，不是学生电脑的时间。

### 学生报「无法获取可信的网络时间」

程序会自动重试一次（只重查失败的时间源，约多 3 秒）。仍失败时让学生
**再点一次【开始考试】**，或改用手机热点——通常是考场网络瞬时抖动。

学生网络不通，或被防火墙拦了。检查网络，或换一台能上网的设备。

### 打包很慢

按规模估算：

| 场次 × 人数 | 信封数 | 约耗时 |
|---|---|---|
| 10 场 × 150 人 | 1,500 | 7 秒 |
| 10 场 × 300 人 | 3,000 | 15 秒 |

慢是正常的——每个学生都要单独做一次内存硬加密（这是防止有人猜学号盗卷的代价）。**不要为了快把 KDF 参数调低**。

### 想保存配置，下次继续改

每次启动都是**空白工程**。要继续上次，点工具栏 **[打开上次工程]**
（按钮悬停会显示上次工程的路径）；也可以 **[打开工程…]** 选任意 `.eesproj`。

工具栏 **[保存工程…]** 存成 `project.eesproj`
（默认打开当前工程目录；打开对话框同时认 `.eesproj` 与旧版 `.json`）。

**打包后还会自动保存一份**（不用手动点）：

- 保存位置 = **[打包]** 页的「工程保存位置」，它**始终显示当前工程所在目录**
  （没打开工程时显示新建工程的目录）；该字段可直接编辑，或点 [浏览…]；
- 已打开工程在同一目录 → **覆盖原文件**；改了目录 → **另存一份到新目录**（旧文件保留）；
- 默认位置是**程序目录**下的 `projects\<包名>-<内容哈希6位>.eesproj`
  （与 `ExamAdmin.exe` 同级，老师看得见、好备份）；
- 程序目录不可写（Program Files / 只读 U 盘）时回退 `%LOCALAPPDATA%\ExamSystem\projects\`；
- **不要**把「工程保存位置」设成考试包输出目录：程序会自动避开，把工程改存到默认目录；
- 每次打包后，**打包日志会写一行「✔ 已保存到工程：<路径>」，并弹窗显示路径**；
- 下次启动**不会**自动打开，需要点 **[打开上次工程]**。

> ⚠ 工程文件里有**标准答案与判分材料**，而且**不在考试包目录里**——
> 不要把它拷到考试包旁边，更不要发给学生。

> 工程文件里**不包含主密钥**，也不包含题库内容（只记路径）。
> 所以换电脑时要保证题库文件在原路径，或重新导入。

## 4. 安全须知（重要，请读完）

### 主密钥

- 它是**唯一**能生成新考试包的东西
- 它**不在**任何生成的包里，也不在 `project.eesproj` 里
- 建议：生成后抄在纸上锁抽屉，或存密码管理器，**不要存在联网的电脑上**

### 学生端包里有什么

学生拿到的 exe 里包含：题目（加密）、每个学生的入场凭证（加密）、
以及**解 header 用的密钥**（混淆后放在文件尾部）。

拿到这个 exe 的人可以：

- ✅ 看到有哪些场次、每场多少人
- ❌ **看不到任何题目**
- ❌ 无法冒充名单外的学号

要拿到题目，必须知道**一个真实在名单里的学号**，并且付出一次内存硬加密的代价
（每次约 0.1 秒）。这就是为什么学号名单本身要保密。

### 不要做的事

- ❌ 不要把题库源文件（含 `answer` 字段）一起发给学生
- ❌ 不要把 `project.eesproj` 发出去（里面有完整学生名单）
- ❌ 不要重复使用主密钥给不同学期的考试
- ❌ 不要在同一个包里塞太多场次（单场出问题影响全部）

## 5. 功能边界

- ✅ 能看题、能作答（单选/多选/判断/填空/改错/问答）、能交卷
- ✅ 答题卡自动加密保存，管理端可批量校验、导出 CSV
- ✅ **自动判分**：单选/多选/判断/填空/改错（按题型勾选，可双击改分）；
  问答由老师人工给分；已判分与未判分分开导出
- ❌ 代码题（题库字段 `judge`：entry/harness/tests）不自动判：
  编译运行学生代码有安全与公平风险，仍人工判
- ✅ 场次可按题库设置**平均难度区间**（只约束抽出的 N 题平均值，不限制单题）
- ✅ 收卷后可生成**缺考名单**（已交/未交/缺考/校验失败/名单外分开列）

需要代码题分数时，用「未判分 CSV」里的题干摘要配合 judge 材料人工阅卷。

## 附：命令行方式（可选）

如果你更喜欢脚本，`_internal\exam-builder.exe` 可以单独使用：

```bash
# 生成主密钥
exam-builder.exe keygen

# 打包（默认把密钥写进包）
exam-builder.exe build \
  --manifest manifest.json \
  --banks ./banks \
  --stub stub-template.exe \
  --out Student.exe

# 校验一个包
exam-builder.exe verify --package Student.exe
```

主密钥建议通过环境变量传，不要写在命令行上（会被同机其他用户从进程列表看到）：

```powershell
$env:EXAM_MASTER = "你的64位十六进制密钥"
```
