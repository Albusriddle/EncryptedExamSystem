# 保密考试系统

管理端编排多场考试 → 打包加密题库 → 学生凭**学号 + 网络时间门禁**解锁个人试卷。

## 教师：下载这个

**下载 `ExamAdmin-<版本>-windows.zip`**（约 54 MB，见本页底部 Assets）

下载 → 解压 → 进 `ExamAdmin` 文件夹 → 双击 `ExamAdmin.exe`。

包内结构：

```
ExamAdmin-<版本>/
├── 开始这里.md      ← 先看这个
├── 使用说明.md      ← 完整手册（常见报错对照、安全须知）
├── ExamAdmin/       ← 程序本体
│   ├── ExamAdmin.exe
│   ├── stub-template.exe
│   └── _internal/
└── 示例题库/        ← 拿来就能试
    ├── 数学.json
    └── 英语.json
```

## 五分钟跑通

| 步骤 | 在哪 | 做什么 |
|---|---|---|
| 1 | `[题库]` | 导入 `示例题库\数学.json` |
| 2 | `[学生]` | 粘贴学号（每行一个），点「应用为学号名单」 |
| 3 | `[场次]` | 新建场次，设时间，勾选科目 |
| 4 | `[打包]` | 点「生成」拿主密钥 → 点「开始打包」 |
| 5 | 分发 | 生成的 `.exe` 发给学生，双击输入学号即可 |

学生**不需要**任何密钥文件、不需要配置、不需要安装。

## 安全要点

- **主密钥**是全系统最重要的东西：不在任何生成的包里，也不在工程文件里，请存进密码管理器。
- 学生端包内嵌了读 header 的密钥（混淆存放）。拿到包的人能看场次时间与人数，**拿不到任何题目**——题库用每场独立密钥加密，且需要合法学号并付出一次内存硬加密。
- 题库源文件（含 `answer`）不要发给学生。

## 已知限制

- 学生端支持**作答**（单选 / 多选 / 补全 / 改错）、**交卷**与到点自动冻结；
- 答题卡加密保存在学生机（`answers-<学号>-<场次>.eea`），教师用管理端
  **收卷判分** 页批量校验并导出 CSV；
- **尚未实现自动判分**：`judge` 材料随题库保留，判分器待做；
- 答题卡加密只能**防误改、防明文**，不能防蓄意篡改——真正的可信仍靠现场监考收卷。

## 校验

- CI 六个 job 全绿（Rust / Python / 端到端 / 管理端打包 / 发布预检 / 密钥扫描），
  测试数量以 CI 为准，这里不再写死；
- 密钥嵌入验收 18 项、发布预检 7 项；
- 教师全流程演练（解压 → 打包 → 学生零配置解锁 → 作答 → 收卷校验）已通过。
