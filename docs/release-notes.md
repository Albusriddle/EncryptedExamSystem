## 五分钟跑通

| 步骤 | 在哪 | 做什么 |
|---|---|---|
| 1 | `[题库]` | 导入 `示例题库\数学.json` |
| 2 | `[学生]` | 粘贴学号（每行一个），点「应用为学号名单」 |
| 3 | `[场次]` | 新建场次，设时间，勾选科目 |
| 4 | `[打包]` | 点「生成」拿主密钥 → 点「开始打包」 |
| 5 | 分发 | 生成的 `.exe` 发给学生，双击输入学号即可 |
| 6 | `[收卷判分]` | 考后拖入 `.eea` → 校验 → 生成成绩 → 导出已判/未判 CSV |

学生**不需要**任何密钥文件、不需要配置、不需要安装。

## 安全要点

- **主密钥**是全系统最重要的东西：不在任何生成的包里，也不在工程文件里，请存进密码管理器。
- 学生端包内嵌了读 header 的密钥（混淆存放）。拿到包的人能看场次时间与人数；不能直接读明文题目，但有合法学号的学生可解密本场题干（答案/judge 已剥离，不能读其他场次或标准答案）。
- 题库源文件（含 `answer`）不要发给学生。

## 已知限制

- 学生端支持**作答**（单选 / 多选 / 判断 / 填空 / 改错 / 问答）、**交卷**与到点自动冻结；
- 答题卡加密保存在学生机（`answers-<学号>-<场次>-<试卷指纹8位>.eea`），教师用管理端
  **收卷判分** 页批量校验并导出 CSV；
- **代码题不自动判分**：`judge` 材料随题库保留，编译运行学生代码有安全与公平风险，仍人工判；
- 自动判分只按题型勾选，暂不支持逐题开关；
- 答题卡加密只能**防误改、防明文**，不能防蓄意篡改——真正的可信仍靠现场监考收卷。
