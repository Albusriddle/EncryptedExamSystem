> 复跑检查用 `AGENTS.md` §2 的那组命令。

## 第一轮（2026-10-22 → v0.1.12）

范围：加密、容器格式、时间门禁、抽题、管理端校验、发布链路。

| # | 问题 | 根因 | 修复 |
|---|---|---|---|
| 1 | `exam_id` 路径穿越：可把 JSON 写到临时目录外 | 只校验非空，随后直接拼进文件名 | 按危险特征拒绝（分隔符/保留名/首尾点），写入端再复核 |
| 2 | 包内 KDF 参数无上限，`m_cost=4e9` 会让客户端申请 TB 级内存 | argon2 的 `MAX_M_COST` 就是 `u32::MAX` | `KdfParams::validate()` 限定范围，`to_argon2` 内强制，`parse_header` 报明确错误 |
| 3 | `kf.txt`（主密钥）、`m1/m2.json` 误入仓库 | 打包测试后 `git add -A` | 删除 + `.gitignore` |
| 4 | UI 校验与打包校验不一致（重复引用题库、跨时区倒挂） | Python 用字符串比较时间；缺重复题库检查 | 改用时间戳比较，补重复题库检查 |
| 5 | 时间不带时区会被静默当成 UTC（整体偏移 8 小时） | 两端解析器都把无偏移当 UTC | 两端强制要求显式时区 |
| 6 | `time_sources` / `time_pubkey` 是死配置 | 从未被任何代码读取 | 删除字段（允许包内指定时间源＝给门禁开后门） |
| 7 | 题号跳转找不到 rect 时无限重绘（CPU 100%） | 无上限 `request_repaint()` | 最多重试 3 帧 |
| 8 | release 构建里仍能用的 `EES_*` 调试开关 | 直接读环境变量 | 收进 `diag_env`/`diag_path`，release 编译为空 |
| 9 | 构建结束后 master 仍留在内存 | worker 对象长期持有 | `finally` 里清空 |
| 10 | 输出目录不可写时抛未捕获异常 | `mkdir` 未包 try | 写探测文件 + 明确提示 |
| 11 | 文档里的水印示例写死 v0.1.4 | — | 改 `<版本号>` 占位 |

## 技术无解项（设计边界，不是待办）

1. **学号是低熵数据**：拿到包的人可以离线枚举名单。Argon2id 参数把成本抬到 10⁵ 个学号约 19 分钟量级，不是密码学保证。
2. **包内嵌的是 `K_manifest` 而非 master**：泄漏后能读场次时间与人数，**读不到题目**；要拿题目仍需猜中学号触发 Argon2id。
3. **有逆向能力 + 知道合法学号的人可以在时间窗内解锁**：纯客户端方案无法消除。
4. **必须联网校时**：完全断网时 fail-closed（宁可考不了，也不能用被篡改的本机时间放行）。
5. **`stub-template.exe` 单独发给学生没有用**：它没有 payload，必须先由 builder 打包。

## 如何复跑

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cd admin && uv sync --extra gui --extra build
uv run pytest -q && uv run ruff check . && uv run ruff format --check .
bash scripts/verify-embed.sh
bash scripts/preflight-release.sh          # 加 --full 连管理端打包一起查
```

CI 用 `.github/workflows/ci.yml` 的六个 job 覆盖同样的事；发布由 `release.yml` 在打 tag 时执行，并附带本版变更。
