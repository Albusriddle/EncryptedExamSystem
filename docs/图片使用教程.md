# 在题库里加图片：一步一步来

- 适用版本：**v1.9.1**（**[插入图片]** 按钮在管理端 [题库] 页）
- **不需要会写代码**，跟着做即可
- 相关：[题库 JSON 规范](题库JSON规范.md) 的「题干内嵌图片」一节、[教师使用手册](教师使用手册.md) 的导入题库一节

图片在本系统里只有一种存在方式：**先把图片变成一段文本，再把这段文本放进题干的 `stem` 字段**。
考试包必须离线自包含（拷一个 exe 到考场就能考），所以不读任何外部图片文件，也不联网加载图片。

---

## 0. 先看效果

管理端 → **[题库]** → **[导入题库]** → 选发布包里的 `示例题库\图片题示例.json`
（仓库里是 `examples/image-question.json`）→ 双击「图片题示例」预览。
打包后学生端看到的就是同一张图；网页考试里也是同一张图。

---

## 1. 七步做完（推荐方式：用 [插入图片] 按钮）

1. 打开 **[题库]** 页；
2. 点 **[插入图片]**；
3. 选一张 **PNG 或 JPEG**（建议 ≤ 1.5 MB、**长边** ≤ 1200 px）；
4. 程序当场检查格式、体积与尺寸：
   - 超过 **1.5 MB**（1 500 000 字节）→ 弹「图片过大」，提示先缩到 1200 px 宽以内，**不生成片段**；
   - 超过 **1200 px** → 弹「尺寸过大」，提示先缩小；
   - 不是有效 PNG / JPEG（读不出宽高）→ 弹「无法识别」；
5. 检查通过后弹「图片说明」，写一句给读屏和失败占位用的说明（可留空）；
6. 点确定 → 弹窗显示「图片 宽×高，N KB。片段已复制…」，形如：

```text
![示意图](data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA…)
```

7. 用记事本 / VS Code 打开题库 JSON，找到那道题的 `"stem"` 字段，
   **把这一整行粘贴进去，让它单独占一行**；保存 → 回管理端重新导入 → 预览确认。

```json
{
  "id": "img-1",
  "type": "single",
  "stem": "观察下面的图片：\n\n![示意图](data:image/png;base64,iVBORw0KGgo…)\n\n图中方块是什么颜色？",
  "options": ["红色", "绿色", "蓝色"],
  "answer": {"kind": "single", "answer": "A"},
  "score": 2
}
```

> **注意**：JSON 字符串里的换行必须写成 `\n`（反斜杠 + n），不能直接按回车。
> 上面示例已经是正确写法。

说明里的 `]` 与 `)` 会被自动换成全角 `］`、`）`（`sanitize_alt()`），否则会提前终止
`![说明](地址)` 的语法，学生端只会看到一段原文。

## 2. 完整的题库示例

`examples/image-question.json` 是一个**可以直接导入**的完整题库，里面有一张 64×64 的红色方块图。
用它对照着改最快：复制整个文件 → 换成你的题目和图片。

```json
{
  "exam_id": "image-demo",
  "title": "图片题示例",
  "pick": 1,
  "questions": [
    {
      "id": "img-1",
      "type": "single",
      "stem": "观察下面的图片：\n\n![示例图](data:image/png;base64,iVBORw0KGgo…)\n\n图中方块是什么颜色？",
      "options": ["红色", "绿色", "蓝色"],
      "answer": {"kind": "single", "answer": "A"},
      "score": 2
    }
  ]
}
```

（图片 base64 已截断，真实文件里的这一段很长，通常几万到几十万字符。）

## 3. 手动方式（批量 / 自动化）

```bash
python tools/embed-image.py 图.png --alt 示意图
```

输出一行 `![示意图](data:image/png;base64,…)`，复制粘贴到 `stem` 即可。
它**不随教师发布包分发**——教师日常请用 [插入图片] 按钮。

| 情况 | 行为 |
|---|---|
| 扩展名不是 `.png` / `.jpg` / `.jpeg` | 退出码 `2`，提示「只支持 PNG/JPEG」 |
| 文件超过 1 500 000 字节 | 退出码 `3`，提示先缩小到 1200 px 宽以内 |
| 正常 | 退出码 `0`，标准输出就是那一行片段 |

`--alt` 里的 `]` / `)` 同样会被换成全角，规则与管理端一致；脚本**不检查尺寸**（宽高只由
[插入图片] 按钮拦），批量生成后请自己确认长边 ≤ 1200 px。

## 4. 规则与限制

| 项 | 要求 |
|---|---|
| 位置 | 只能放在 **`stem`** 里，且**独占一行**；选项里写 `![](...)` 会按普通文字显示 |
| 格式 | PNG / JPEG（`data:image/png`、`data:image/jpeg`）；`image/jpg` 管理端也认，但**网页端只识别 png/jpeg**，请统一用 `image/jpeg` |
| 建议大小 | ≤ **1.5 MB**、**长边** ≤ **1200 px**（导入时**只提示、不阻止**；[插入图片] 会直接拦下并让你先压缩） |
| 学生端硬上限 | **4 MB**、**4096 × 4096 px**（解码前就限死）；超了显示 `[图片无法显示：说明]` |
| 解码失败 | 显示 `[图片无法显示：说明]`，**不影响其它题目**，也不会每帧重试 |
| 网页端 | 只识别 `data:image/png` 与 `data:image/jpeg`；超限或坏数据按纯文本/空图显示 |
| 网络 | 不需要联网，图片**内嵌**在题库里，考试包离线自包含 |
| 内存 | 客户端纹理缓存上限 128 MB 且最多 32 张；失败键单独记 32 条，避免反复重试 |

**图片太大怎么办**：用系统「画图」或任何看图软件把宽度改到 1200 px 以内；
照片存成 JPEG（体积通常只有 PNG 的 1/5），截图 / 线条图存成 PNG。
不要反复二次压缩同一个文件——每压一次都会更糊，体积不一定降得更多。

---

## 5. 一步一步自检（做完这 7 条再打包）

1. 打开题库 JSON，确认那一行以 `![` 开头、以 `)` 结尾，**中间没有换行**；
2. 确认这一行在 `"stem"` 里，前后各有 `\n\n`，或确实独立成行；
3. 确认图片是 PNG / JPEG，且 ≤ 1.5 MB、长边 ≤ 1200 px（[插入图片] 已经替你挡过）；
4. 回到管理端重新导入，确认**没有**「图片超过建议上限 / 尺寸超过建议上限 / base64 已损坏」的提示；
5. 双击题库行预览，确认能看到 `[图片 说明]` 占位（说明片段被识别到了）；
6. 用测试学号打一个测试包，打开学生端确认图片真的显示（至少不是 `[图片无法显示]`）；
7. 如果一道题有多张图，确认每张都独占一行，且题库文件没有被撑得过大。

> 第 5、6 条不能混：**管理端预览不渲染图片**，它只把识别到的 `![…](…)` 标成文字占位
> （`[图片 说明]`）；真图只在学生端（桌面 / 网页）出现。所以第 6 条必须做，
> 预览「看不到图」**不是** bug。

## 6. 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 学生端显示 `[图片无法显示：…]` | 超过 4 MB / 4096 px 硬上限；或 base64 被截断 | 用 [插入图片] 重新生成，别手工复制半截 |
| 预览里只有 `[图片 说明]` 这样的占位，没有真图 | **管理端预览不渲染图片**，只标出识别到的图片片段 | 属正常；以学生端为准，打包后实机看一眼 |
| 题目里出现 `![...](...)` 原文 | 图片没独占一行，或写在了选项里；或网页端用了 `image/jpg` | 挪到 `stem`，前后各留一个空行；网页端改用 `image/jpeg` |
| 导入时提示「图片超过建议上限」 | 图太大 / 尺寸太大 | 缩到 1200 px 以内，照片改 JPEG |
| JSON 报错 `Invalid control character` | 直接按了回车 | 用 `\n` 表示换行 |
| 说明文字显示不全 / 语法断掉 | 说明里带 `]` 或 `)` | 用 [插入图片] 生成（会自动转全角），或手写成 `］`、`）` |
| 图片能显示但排版错乱 | 图片与文字写在同一行 | 图片必须**独占一行**，不做图文混排 |
| 打包后图变糊 | 原图被压过 | 保持原分辨率 ≤ 1200 px，不要二次压缩 |
| 手机上（网页考试）看不到图 | 用了 `image/jpg`，或 data URI 被换行截断 | 用 `image/jpeg`，整行不换行 |
| 换个电脑打开题库，图片不见了 | 用外部路径 / URL 引用了图片 | 只能用 `data:image/…`，图片必须在 `stem` 里 |

## 7. 与其它 Markdown 语法的关系

图片只是题干 Markdown 子集里的一项，可以和其它语法混用（但图片本身必须独占一行）：

| 语法 | 能否与图片同题 | 网页端是否渲染 |
|---|---|---|
| 代码块 ` ``` ` | 能 | 能 |
| 表格 | 能 | 否（按纯文本显示） |
| 加粗 / 行内代码 / 列表 / 引用 | 能 | 否（按纯文本显示） |
| 链接、斜体、删除线、嵌套列表、HTML | **不支持**，按纯文本显示 | 否 |

> 题干里的图片走的是 `![说明](data:…)`，**不是**外部 URL。写 `https://…/a.png` 不会联网加载，
> 只会按普通文字显示——考试包必须离线自包含，这一点不能妥协。
