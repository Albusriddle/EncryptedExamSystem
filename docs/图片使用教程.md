# 在题库里加图片：一步一步来

- 适用版本：**v1.3.1**（图片功能自 v0.5.0 起；**[插入图片]** 按钮自 v0.5.1 起）
- **不需要会写代码**，跟着做即可
- 相关：[题库JSON规范](题库JSON规范.md) §1.5–1.6、[教师使用手册](教师使用手册.md) §2.1

---

## 0. 先看效果

管理端 → **[题库]** → **[导入题库]** → 选发布包里的 `示例题库\图片题示例.json`
（仓库里是 `examples/image-question.json`）→ 双击「图片题示例」预览。
打包后学生端看到的就是同一张图。

---

## 1. 最省事的方式：用 [插入图片] 按钮

1. 打开 **[题库]** 页；
2. 点 **[插入图片]**；
3. 选一张 **PNG 或 JPEG**（建议 ≤ 1.5 MB、≤ 1200 px）；
4. 程序检查格式、体积与尺寸，通过后弹窗让你写一句「图片说明」（可留空）；
5. 点确定 → 片段已复制到剪贴板，形如：

```text
![示意图](data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA…)
```

6. 用记事本 / VS Code 打开题库 JSON，找到那道题的 `"stem"` 字段，
   **把这一整行粘贴进去，让它单独占一行**；
7. 保存 JSON → 回到管理端重新导入 → 预览确认。

```json
{
  "id": "img-1",
  "type": "single",
  "stem": "观察下面的图片：\n\n![示意图](data:image/png;base64,iVBORw0KGgo…)\n\n图中方块是什么颜色？",
  "options": ["红色", "绿色", "蓝色"],
  "answer": {"kind": "single", "answer": "A"},
  "score": 2
}
```

> **注意**：JSON 字符串里的换行必须写成 `\n`（反斜杠 + n），不能直接按回车。
> 上面示例已经是正确写法。

程序会自动处理说明里的 `]` 与 `)`：它们会换成全角 `］`、`）`，否则会提前终止
`![说明](地址)` 的语法，学生端只会看到一段原文（v0.5.2 起的 `sanitize_alt()`）。

## 2. 完整的题库示例

`examples/image-question.json` 是一个**可以直接导入**的完整题库，里面有一张 64×64 的红色方块图。
用它对照着改最快：复制整个文件 → 换成你的题目和图片。

```json
{
  "exam_id": "image-demo",
  "title": "图片题示例",
  "pick": 1,
  "questions": [
    {
      "id": "img-1",
      "type": "single",
      "stem": "观察下面的图片：\n\n![示例图](data:image/png;base64,iVBORw0KGgo…)\n\n图中方块是什么颜色？",
      "options": ["红色", "绿色", "蓝色"],
      "answer": {"kind": "single", "answer": "A"},
      "score": 2
    }
  ]
}
```

（图片 base64 已截断，真实文件里的这一段很长，通常几万到几十万字符。）

## 3. 手动方式（批量 / 自动化）

```bash
python tools/embed-image.py 图.png --alt 示意图
```

输出一行 `![示意图](data:image/png;base64,…)`，复制粘贴到 `stem` 即可。
脚本只支持 PNG/JPEG，超过 **1 500 000 字节**会直接报错并提示先压缩。
它**不随教师发布包分发**——教师日常请用 [插入图片] 按钮。

---

## 4. 规则与限制

| 项 | 要求 |
|---|---|
| 位置 | 只能放在 **`stem`** 里，且**独占一行**；选项里写 `![](...)` 会按普通文字显示 |
| 格式 | PNG / JPEG（`data:image/png`、`data:image/jpeg`；`image/jpg` 也认，但推荐 `image/jpeg`） |
| 建议大小 | ≤ **1.5 MB**、≤ **1200 px**（导入 / 打包前会提示） |
| 学生端硬上限 | **4 MB**、**4096 px**；超了显示 `[图片无法显示：说明]` |
| 解码失败 | 显示 `[图片无法显示：说明]`，**不影响其它题目** |
| 网络 | 不需要联网，图片**内嵌**在题库里，考试包离线自包含 |
| 内存 | 客户端纹理缓存上限 128 MB 且最多 32 张；失败键单独记 32 条，避免反复重试 |

**图片太大怎么办**：用系统「画图」或任何看图软件把宽度改到 1200 px 以内；
照片存成 JPEG（体积通常只有 PNG 的 1/5），截图 / 线条图存成 PNG。

---

## 5. 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 学生端显示 `[图片无法显示：…]` | 超过 4 MB / 4096 px 硬上限；或 base64 被截断 | 用 [插入图片] 重新生成，别手工复制半截 |
| 预览里看到 `[图片 说明]`，学生端却看不到 | 管理端预览只是文字占位，实际以学生端为准 | 打包后实机看一眼 |
| 题目里出现 `![...](...)` 原文 | 图片没独占一行，或写在了选项里 | 挪到 `stem`，前后各留一个空行 |
| 导入时提示「图片超过建议上限」 | 图太大 | 缩到 1200 px 以内，照片改 JPEG |
| JSON 报错 `Invalid control character` | 直接按了回车 | 用 `\n` 表示换行 |
| 说明文字显示不全 / 语法断掉 | 说明里带 `]` 或 `)` | 用 [插入图片] 生成（会自动转全角），或手写成 `］`、`）` |
| 图片能显示但排版错乱 | 图片与文字写在同一行 | 图片必须**独占一行**，不做图文混排 |
| 打包后图变糊 | 原图被压过 | 保持原分辨率 ≤ 1200 px，不要二次压缩 |

---

## 6. 自检清单

- [ ] 图片那一行以 `![` 开头、以 `)` 结尾，中间**没有换行**；
- [ ] 整行在 `stem` 里，前后各有 `\n\n`（或独立成行）；
- [ ] 图片是 PNG / JPEG，且 ≤ 1.5 MB、≤ 1200 px；
- [ ] 导入时没有「图片超过建议上限」的提示；
- [ ] 管理端预览能看到 `[图片 说明]` 占位（说明片段被识别到了）；
- [ ] 打包后学生端实机能看到图（至少不是 `[图片无法显示]`）；
- [ ] 若一张题干放多张图，每张都独占一行，且总量不把题库文件撑得过大。

---

## 7. 与其它 Markdown 语法的关系

图片只是题干 Markdown 子集里的一项，可以和其它语法混用（但图片本身必须独占一行）：

| 语法 | 能否与图片同题 |
|---|---|
| 代码块 ` ``` ` | 能 |
| 表格 | 能 |
| 加粗 / 行内代码 / 列表 / 引用 | 能 |
| 链接、斜体、嵌套列表、HTML | **不支持**，按纯文本显示 |

> 题干里的图片走的是 `![说明](data:…)`，**不是**外部 URL。写 `https://…/a.png` 不会联网加载，
> 只会按普通文字显示——考试包必须离线自包含，这一点不能妥协。
