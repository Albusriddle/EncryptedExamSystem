# 在题库里加图片：一步一步来

> 适用版本：v0.6.3 及以后。**不需要会写代码**，跟着做即可。

---

## 0. 先看效果

打开管理端 → **[题库]** → 点 **[导入题库…]** → 选 `examples/image-question.json` →
选中「图片题示例」→ 双击预览，能看到一道带图的题。

把它打包后给学生，学生看到的也是这张图。

---

## 1. 最省事的方式：用「插入图片…」按钮

1. 打开管理端 **[题库]** 页；
2. 点 **[插入图片…]**；
3. 选一张 **PNG 或 JPEG**（建议 ≤1.5 MB、≤1200 px）；
4. 程序会检查尺寸/体积，通过后弹窗让你写一句"图片说明"（可留空）；
5. 点确定 → 片段已复制到剪贴板，形如：

```
![示意图](data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...)
```

6. 打开你的题库 JSON（用记事本 / VS Code / 任何编辑器），找到那道题的 `"stem"` 字段，
   **把这一整行粘贴进去，单独占一行**：

```json
{
  "id": "img-1",
  "type": "single",
  "stem": "观察下面的图片：\n\n![示意图](data:image/png;base64,iVBORw0KGgo...)\n\n图中方块是什么颜色？",
  "options": ["红色", "绿色", "蓝色"],
  "answer": {"kind": "single", "answer": "A"},
  "score": 2
}
```

7. 保存 JSON → 回到管理端重新导入 → 预览确认。

> **注意**：JSON 字符串里的换行必须写成 `\n`（反斜杠 + n），不能直接按回车。
> 上面示例已经是正确写法。

---

## 2. 完整的题库示例

`examples/image-question.json` 是一个**可以直接导入**的完整题库，里面有一张 64×64 的红色方块图。
用它对照着改最快：复制整个文件 → 换成你的题目和图片。

文件长这样（图片 base64 已截断）：

```json
{
  "exam_id": "image-demo",
  "title": "图片题示例",
  "pick": 1,
  "questions": [
    {
      "id": "img-1",
      "type": "single",
      "stem": "观察下面的图片：\n\n![示例图](data:image/png;base64,iVBORw0KGgo...)\n\n图中方块是什么颜色？",
      "options": ["红色", "绿色", "蓝色"],
      "answer": {"kind": "single", "answer": "A"},
      "score": 2
    }
  ]
}
```

## 3. 手动方式（批量/自动化）

```bash
python tools/embed-image.py 图.png --alt 示意图
```

输出一行 `![示意图](data:image/png;base64,…)`，复制粘贴到 `stem` 即可。
脚本只支持 PNG/JPEG，超过 1.5 MB 会直接报错并提示先压缩。

---

## 4. 规则与限制

| 项 | 要求 |
|---|---|
| 位置 | 只能放在 **`stem`** 里，且**独占一行**（选项里不支持图片） |
| 格式 | PNG / JPEG（`data:image/png` 或 `data:image/jpeg`） |
| 建议大小 | ≤ 1.5 MB、≤ 1200 px |
| 学生端硬上限 | 4 MB、4096 px（超了显示 `[图片无法显示]`） |
| 网络 | 不需要联网，图片是**内嵌**在题库里的 |

---

## 5. 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 学生端显示 `[图片无法显示：…]` | 图片超过硬上限 / base64 被截断 | 重新用按钮生成，别手工复制半截 |
| 预览里看到 `[图片 说明]`，学生端却看不到 | 预览只是文字占位，实际以学生端为准 | 打包后实机看一眼 |
| 题目里出现 `![...](...)` 原文 | 图片没独占一行，或写在选项里 | 挪到 `stem` 单独一行 |
| 导入题库时提示"图片超过建议上限" | 图太大 | 用画图/看图软件缩到 1200 px 以内，照片存 JPEG |
| JSON 报错"Invalid control character" | 直接按了回车 | 用 `\n` 表示换行 |

---

## 6. 自检清单

- [ ] 图片那一行以 `![` 开头、以 `)` 结尾，中间没有换行；
- [ ] 整行在 `stem` 里，前后各有 `\n\n`；
- [ ] 导入时没有"图片超过建议上限"的提示；
- [ ] 打包后学生端能看到图（或至少不是 `[图片无法显示]`）。
