# 签名时间令牌协议（v1）

> 阶段 4.2；服务端尚未随仓库部署，本文件定义协议，客户端与管理端已支持。
> 默认 `off`，不影响不配置的学校。

## 1. 请求

```
GET {url}?nonce=<32 位小写十六进制>
```

`nonce` 由客户端每次随机生成（16 字节），用于防重放。

## 2. 响应

```json
{"t": 1760000000, "n": "<原 nonce>", "sig": "<base64 Ed25519 签名>"}
```

- `t`：Unix 秒；
- `n`：必须与请求 nonce 完全一致；
- `sig`：对 `"{t}:{n}"`（UTF-8，无空格）用 Ed25519 私钥签名。

## 3. 客户端校验

1. `nonce` 匹配；
2. 用包内 `time.pubkey` 验签；
3. 取 `t` 作为考试时间（不信任本机时钟）；
4. 本机时钟偏差超过 `max_skew` 只打印警告，不拒绝（本机时钟可被学生修改）。

## 4. 模式

| mode | 行为 |
|---|---|
| `off` | 不请求令牌，沿用 HTTPS Date |
| `prefer` | 先试令牌，失败回退 HTTPS Date 并在日志警告 |
| `require` | 无有效令牌直接拒绝开考 |

## 5. 最小服务端示例（Python + Flask）

```python
# pip install flask cryptography
import base64, os, time
from flask import Flask, request, jsonify
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey

app = Flask(__name__)
# 32 字节 seed，base64；生产环境放密钥管理系统
SK = Ed25519PrivateKey.from_private_bytes(base64.b64decode(os.environ["TIME_SK"]))

@app.get("/time")
def time_token():
    n = request.args.get("nonce", "")
    if not n or len(n) != 32:
        return jsonify(error="bad nonce"), 400
    t = int(time.time())
    sig = base64.b64encode(SK.sign(f"{t}:{n}".encode())).decode()
    return jsonify(t=t, n=n, sig=sig)
```

> 私钥只放在服务端；公钥填进管理端「令牌公钥」。
> 启用 `require` 的包是容器 v5；若同时启用大题则为 v6。
> 旧学生端会明确拒绝打开，请同步更新学生端（v0.14.0+）。
