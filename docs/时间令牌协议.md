# 签名时间令牌协议（v1）

> 对应实现阶段 4.2。**服务端不随仓库部署**（`worker/` 为空）：本文件定义协议，客户端与管理端已支持。
> 默认 `mode = off`，不配置的学校不受影响。教师配置见 [教师使用手册](教师使用手册.md) §5.5，
> 容器门禁见 [安全边界与威胁模型](安全边界与威胁模型.md) §6。适用版本 **v1.9.0**；
> 协议自 v0.13.0 起，`mode != off` 的包写容器 **v5**。

## 1. 目的与边界

HTTPS `Date` 头能挡住「改本机时间」，挡不住伪造 TLS / 劫持单个时间源。签名令牌把「可信时间」
从「某个网站说的」变成「持有私钥的服务说的」：客户端内置 Ed25519 **公钥**，服务端对
`时间戳 + 一次性 nonce` 签名，验签通过才采信；nonce 每次随机，服务端**无需记录状态**即可让重放失效。

**边界**：只保证「时间来自持有私钥的服务」。不防服务宕机（`require` 会因此无法开考），
也**不提供**服务端防重放部署——那需要服务端自己记录 nonce，本仓库不含该实现。

## 2. 请求

```text
GET {url}?nonce=<32 位小写十六进制>
```

`nonce` 每次随机生成（16 字节 → 32 hex）；若 `url` 已含 `?`，客户端用 `&` 追加。只允许 `https://`
（`http://` 在 `TimeConfig::validate()` 就被拒）。超时 **3 秒**，响应体上限 **1 000 000 字节**
（Windows 走 WinHTTP 读循环，非 Windows 走 `curl -fsSL --max-filesize 1000000 --max-time <秒>`）；
非 2xx 直接失败，报 `时间服务 HTTP <code>`。

## 3. 响应

```json
{"t": 1760000000, "n": "<原 nonce>", "sig": "<base64 Ed25519 签名>"}
```

| 字段 | 说明 |
|---|---|
| `t` | Unix 秒（整数） |
| `n` | 必须与请求 nonce **完全一致** |
| `sig` | 对 `"{t}:{n}"`（UTF-8，无空格）签名，标准 base64（64 字节） |

被签名的原文形如 `1760000000:3f2a9c…`——冒号是 ASCII，前后**不能有空格**。

## 4. 客户端校验顺序

1. `validate()`：`mode ∈ {off, prefer, require}`、`url` 以 `https://` 开头、`pubkey` 是 32 字节 base64；
2. 解析 JSON（失败 → `时间令牌 JSON 无法解析`）；`n == nonce`（不等 → `nonce 不匹配（疑似重放）`）；
3. base64 解公钥（非 32 字节报错）→ `VerifyingKey::from_bytes`；base64 解签名（非 64 字节报错）→ 验签；
4. 取 `t` 作为考试时间。**本机时钟只用于警告**，不参与放行判定；失败原因原样上报，不静默降级。

## 5. 模式

| mode | 行为 | 容器版本 |
|---|---|---|
| `off`（默认） | 不请求令牌，沿用三源 HTTPS `Date` 中位数 | v4 |
| `prefer` | 先试令牌；失败回退 HTTPS `Date` 并在日志警告 | v5 |
| `require` | 无有效令牌直接拒绝开考（断网 / 服务挂会无法开考） | v5 |

未知 `mode` **不会**静默回退——`validate()` 直接报错。`max_skew`（默认 300 秒）是「本机时钟偏差警告阈值」，超过只打印一行警告，**不参与放行 / 拒绝**：本机时钟可被学生修改，用它做判据等于把门禁交给学生。

## 6. 配置位置

令牌配置随包以加密形式放在容器 Header 的 `time` 字段（`schemas/manifest.schema.json` 的 `TimeConfig`）：

```json
{"time": {"mode": "prefer", "url": "https://time.example.edu/api/time", "pubkey": "<base64 32 字节>", "max_skew": 300}}
```

管理端在 **[打包]** 页填「时间令牌」「令牌 URL」「令牌公钥」「时钟偏差警告阈值」。
`mode = off` 时其余字段可不填；`mode != off` 时 URL 与公钥都必填。

## 7. 最小服务端示例（Python + Flask）

```python
# pip install flask cryptography
import base64, os, time
from flask import Flask, jsonify, request
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey

app = Flask(__name__)
SK = Ed25519PrivateKey.from_private_bytes(base64.b64decode(os.environ["TIME_SK"]))
print("pubkey(base64) =", base64.b64encode(SK.public_key().public_bytes_raw()).decode())

@app.get("/api/time")
def time_token():
    n = request.args.get("nonce", "")
    if len(n) != 32 or any(c not in "0123456789abcdef" for c in n):
        return jsonify(error="bad nonce"), 400
    t = int(time.time())
    return jsonify(t=t, n=n, sig=base64.b64encode(SK.sign(f"{t}:{n}".encode())).decode())
```

部署后 curl 自查：`NONCE=$(python -c "import secrets;print(secrets.token_hex(16))")`，
再 `curl -fsS "https://…/api/time?nonce=$NONCE"`；`n` 必须与 `$NONCE` 完全一致，`t` 与 `date +%s` 相差几秒内。
私钥**只在服务端**；公钥（服务端打印的 44 字符 base64）填进管理端；必须部署在 HTTPS 上。

## 8. 常见错误

| 提示 | 原因 | 怎么办 |
|---|---|---|
| `只支持 https:// 开头的地址` | 配了 `http://` 或裸域名 | 改成 `https://…/api/time` |
| `时间令牌公钥必须是 32 字节 Ed25519 公钥` | 填成了 PEM / hex / 长度不对 | 用服务端打印的 base64 44 字符值 |
| `nonce 不匹配（疑似重放）` | 服务端回显了别的 nonce，或中间有缓存 | 关掉 CDN / 反代缓存，确认原样回显 `n` |
| `时间令牌签名验证失败` | `"{t}:{n}"` 拼法不一致（多了空格 / 少了冒号） | 严格按 `f"{t}:{n}"` 生成签名原文 |
| `签名长度不是 64 字节` / `时间服务 HTTP 404 / 500` | 用了 hex 而不是 base64，或被截断 / 路径写错、服务端异常 | 用标准 base64 输出；核对 `url` 并查服务端日志 |

## 9. 自检清单

- [ ] `url` 是 `https://`，公网可达，证书链正常；公钥是 base64 / 32 字节，不是 PEM、不是 hex；
- [ ] 签名原文是 `"{t}:{n}"`（冒号 ASCII、无空格），服务端原样回显 nonce，`curl` 取到的时间对得上；
- [ ] 管理端先选 `prefer` 试跑，日志无告警后再考虑 `require`；学生端满足容器 v5 最低要求（v0.15.0+），并已与考务确认 `require` 的后果（服务挂了就不能开考）。
