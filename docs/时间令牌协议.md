# 签名时间令牌协议（v1）

> 阶段 4.2；服务端尚未随仓库部署，本文件定义协议，客户端与管理端已支持。
> 默认 `off`，不影响不配置的学校。

## 1. 请求

```
GET {url}?nonce=<32 位小写十六进制>
```

`nonce` 由客户端每次随机生成（16 字节），用于防重放。

## 2. 响应

```json
{"t": 1760000000, "n": "<原 nonce>", "sig": "<base64 Ed25519 签名>"}
```

- `t`：Unix 秒；
- `n`：必须与请求 nonce 完全一致；
- `sig`：对 `"{t}:{n}"`（UTF-8，无空格）用 Ed25519 私钥签名。

## 3. 客户端校验

1. `nonce` 匹配；
2. 用包内 `time.pubkey` 验签；
3. 取 `t` 作为考试时间（不信任本机时钟）；
4. 本机时钟偏差超过 `max_skew` 只打印警告，不拒绝（本机时钟可被学生修改）。

## 4. 模式

| mode | 行为 |
|---|---|
| `off` | 不请求令牌，沿用 HTTPS Date |
| `prefer` | 先试令牌，失败回退 HTTPS Date 并在日志警告 |
| `require` | 无有效令牌直接拒绝开考 |

## 5. 最小服务端示例（Cloudflare Worker）

```js
export default {
  async fetch(req) {
    const n = new URL(req.url).searchParams.get("nonce") || "";
    const t = Math.floor(Date.now() / 1000);
    // 用 WebCrypto 导入 Ed25519 私钥，对 `${t}:${n}` 签名，返回 JSON
  }
}
```

> 私钥只放在服务端；公钥填进管理端「令牌公钥」。
