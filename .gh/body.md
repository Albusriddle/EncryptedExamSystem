# 保密考试系统 v0.1.0

管理端编排多场考试 → 打包加密题库 → 学生凭**学号 + 网络时间门禁**解锁个人试卷。

## 教师：下载这个

**[`ExamAdmin-v0.1.0-windows.zip`](https://github.com/Albusriddle/EncryptedExamSystem/releases/download/v0.1.0/ExamAdmin-v0.1.0-windows.zip)**（54 MB）

下载 → 解压 → 进 `ExamAdmin` 文件夹 → 双击 `ExamAdmin.exe`。

包内结构：

```
ExamAdmin-v0.1.0/
├── 开始这里.md      ← 先看这个
├── 使用说明.md      ← 完整手册（常见报错对照、安全须知）
├── ExamAdmin/       ← 程序本体
│   ├── ExamAdmin.exe
│   ├── stub-template.exe
│   └── _internal/
└── 示例题库/        ← 拿来就能试
    ├── 数学.json
    └── 英语.json
```

## 五分钟跑通

| 步骤 | 在哪 | 做什么 |
|---|---|---|
| 1 | `[题库]` | 导入 `示例题库\数学.json` |
| 2 | `[学生]` | 粘贴学号（每行一个），点「应用为学号名单」 |
| 3 | `[场次]` | 新建场次，设时间，勾选科目 |
| 4 | `[打包]` | 点「生成」拿主密钥 → 点「开始打包」 |
| 5 | 分发 | 生成的 `.exe` 发给学生，双击输入学号即可 |

学生**不需要**任何密钥文件、不需要配置、不需要安装。

## 安全要点

- **主密钥**是全系统最重要的东西：不在任何生成的包里，也不在工程文件里，请存进密码管理器。
- 学生端包内嵌了读 header 的密钥（混淆存放）。拿到包的人能看场次时间与人数，**拿不到任何题目**——题库用每场独立密钥加密，且需要合法学号并付出一次内存硬加密。
- 题库源文件（含 `answer`）不要发给学生。

## 已知限制

这一版学生端是**试卷展示器**：能看题、能看选项、能看分值；
**不支持作答、交卷、自动判分**。若考试需要收答案，请另备手段。
